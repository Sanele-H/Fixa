# Fixa

> Hire someone nearby in your own language, without handing your number or address to a stranger, **and give skilled newcomers a fair shot at their first job.**

This is our hackathon build: a 7-day sprint (Sat 26 Sep → pitch on Sat 3 Oct) by 4 people, ending in one demo on two phones.

## Start here

The project scaffold is waiting for team review on the [`project-scaffold`](https://github.com/Sanele-H/Fixa/tree/project-scaffold) branch. It has the setup, the folders, the agreed interfaces and a guide for each role. Once everyone has reviewed it and agrees, it is merged into `main` and replaces this page.

```bash
git clone https://github.com/Sanele-H/Fixa.git
cd Fixa
git checkout project-scaffold
```

Then follow the Quick start and "Your first hour" in [that branch's README](https://github.com/Sanele-H/Fixa/blob/project-scaffold/README.md).
